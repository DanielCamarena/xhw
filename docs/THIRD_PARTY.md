# Scientific sources, provenance and licenses

xHW is Copyright 2026 Daniel Camarena and is distributed under Apache-2.0.
The official [license text](../LICENSE) is preserved unchanged. External licenses
apply to their own projects; the xHW license does not relicense them.

No upstream source code, articles, real datasets or model weights are bundled.
The implementation uses published methods and separately installed numerical
dependencies. The small synthetic inputs and numerical outputs in
`tests/reference/` were generated by external software; they are test evidence,
not vendored implementations. SHA-256 checksums identify every registered output.
Generation timestamps and software sessions identify the numerical references.

The climatological TX/TN comparison uses climdex.pcic's exported functions and
Climpact-style warm-run outputs produced in R. The source audit identifies
[Climpact](https://github.com/ARCCSS-extremes/climpact) as GPL-3.0. Its code is not
distributed. marEx labeling comparisons use its structured labeling call; merge
comparisons use overlap 0.5, nearest-neighbour partitioning and no temporal/spatial
filling. Known differences are described in [validation](VALIDATION.md).

Core dependencies are NumPy, xarray and SciPy, installed separately, not vendored.
Dask is optional. statsmodels (BSD-3-Clause) and pygam (Apache-2.0) provide optional
dynamic engines. pytest, Ruff and h5netcdf/h5py support development and validation.
Licenses observed from dependency metadata are distinct from a full file-by-file
legal audit. No license from an article is treated as permission to copy its code.
